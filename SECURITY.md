# Security and publication boundary

This experimental addon writes to game memory and, for money bonuses, the copied game's wallet. Use disposable copies. Ownership/layout/source checks are guardrails, not a security certification or guarantee against save corruption.

The companion has no network listener; the portable configuration disables PINE. The public export excludes private backend/authentication patches, tokens, records, saves, BIOS/game/VIP/car files and generated byte guard headers. Generated guards come only from the user's own compatible ELF. They must stay local.

Do not send passwords, tokens, game dumps, BIOS, memory cards, inventory DBs or raw private logs in an issue. Report a sanitized symptom, version and exact refusal message. Use GitHub private vulnerability reporting if enabled; do not disclose an exploitable issue with personal data publicly. Maintain tests and bounded input validation before merging fixes.

Public history starts fresh; the private research repository was not made public. Release files are allowlisted and scanned. No repository audit can certify every runtime input or third-party binary. A future player binary needs a clean upstream build, complete corresponding source/notices and fresh-machine validation.
